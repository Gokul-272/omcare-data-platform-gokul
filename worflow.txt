

1. Push the feature branch (feature/gokul-setup) to GitHub.

2. Create a Pull Request (PR) from feature/gokul-setup into the main branch.

3. Request code review from teammates. They review the code, suggest improvements, and approve the PR.

6. After merging, the deployment pipeline is triggered automatically (or manually if required) to deploy the latest changes to the target environment.

7. Verify that the deployment completed successfully and the application is working as expected.
